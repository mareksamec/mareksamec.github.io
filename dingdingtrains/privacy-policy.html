Ding Ding Trains privacy policy

Last updated: 21 October 2026

Ding Ding Trains is a train game for young children, made by Marek Samec.

What the game collects

Nothing. The game does not collect, store, or share any personal data, and it sends nothing anywhere.

  • It has no accounts, sign-in, ads, analytics, tracking, or in-app purchases.
  • It does not use the internet. The app asks for no Android permissions at all, so it cannot reach the network, the camera, the microphone, contacts, or the device's location.
  • It contains no third-party code that collects data.

What stays on the device

The game keeps a small save file on the phone or tablet: the stars and coins earned in each level, and whether the sound is on. It never leaves the device. Uninstalling the game deletes it.

Children

The game is made for children. Because it collects no personal information from anyone, it collects none from children.

Changes

If a future version changes any of this, this page will be updated before that version is released, and the date at the top will change.
